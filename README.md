# HTAH Adventure

## Tính năng trong `www/index.html`
- Multiplayer Host/Guest qua WebRTC/PeerJS.
- Phòng chơi và mã phòng.
- Host bắt đầu trận: phòng biến mất ngay và người chơi vào cùng ải.
- Khách chết -> Hồn Ma, chỉ di chuyển/theo Host.
- Host chuyển ải -> Hồn Ma chuyển theo.
- Ải dừng chân có Giấy Hồi Sinh và chọn người chơi để hồi sinh.
- Hiệu ứng nút Bắt Đầu.
